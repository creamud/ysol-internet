# YSOL INTERNET

**[Tarayıcıda oyna](https://creamud.github.io/ysol-internet/)**

YSOL INTERNET, kendi internet kafeni işlettiğin birinci şahıs 3D simülasyon. Kafene isim ver, kasalardan bilgisayarları aç, resepsiyonda müşterileri onayla ve seans ücretlerini tahsil et. Zamazingo’dan ekipman sipariş ederek kafeni büyütebilir, biriktirdiğin parayla YSOL GT’yi alıp mahallede sürebilirsin.

## Kontroller

| Tuş | İşlev |
| --- | --- |
| WASD | Yürü veya araç sür |
| Fare | Etrafa bak |
| E | Etkileşim, resepsiyona otur / kalk veya araçtan in |
| P | Telefonu aç |
| C | Elindeki kahveyi iç |
| Space | Zıpla veya araçla fren yap |
| Esc | Duraklat |

## Kayıt

Oyun kafe adını, paranı, saati, aldığın eşyaları, siparişlerini ve aktif seansları tarayıcı profiline otomatik kaydeder. Aynı adresi aynı tarayıcı profiliyle yeniden açınca **Devam et** düğmesiyle oyuna dönebilirsin. Kayıtlar cihazlar arasında eşitlenmez. Site verilerini silmek ilerlemeni siler.

Masaüstü tarayıcı, WebGL ve fare kilidi gerekir. Oyun Three.js ile çalışır.
